Braxon's Sticky Notes - A Chrome Extension

Braxon's Sticky Notes is a lightweight browser extension for jotting down quick notes without leaving your toolbar. It supports multiple notes you can switch between instantly, basic rich-text formatting for bold and italics, and two visual themes — a classic yellow legal-pad style and a minimal modern look. An optional delete confirmation helps prevent accidental data loss, and built-in export/import lets you back up your notes as a JSON file or move them between installs. All data is stored locally through the browser's native storage API. Works across Chromium-based browsers including Chrome, Edge, and Brave.

Install Instructions

Watch on YouTube:

Or follow instructions below:

1. Click the Download Link above to download the latest version, the file should look similar to "braxon.sStickyNotes_v1.0.0.zip".

2. Unzip the file to a folder you'll keep around. Your browser loads the extension directly from this folder, so don't delete or move it after installing.

3. Open your browser's extensions page.

4. Turn on Developer mode using the toggle in the top-right corner of the page.

5. Click the Load unpacked button.

6. Select the folder you unzipped in step 2.

7. Braxon's Sticky Notes should now appear in your toolbar. Click the puzzle-piece icon and pin it for quick access.


Updating Instructions

1. Click the Download Link above to download the newest version; the file should look similar to "braxon.sStickyNotes_vX.X.X.zip".

2. Unzip the new file into the same folder you used when you first installed the extension, overwriting the old files.

3. Open your browser's extensions page.

4. Find the Braxon's Sticky Notes card and click the reload icon on it. This reloads the extension with the new files.
